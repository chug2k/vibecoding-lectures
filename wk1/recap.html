⚡ Gotchas & live notes

The things that came up live and aren't on the slides.

Biggest snag

Couldn't log into Claude Code? Accept the invite first.

Several people hit a wall at login. The fix: there's an invite email from the org you have to accept first — only then will claude let you log in. Still stuck? Find that invite and accept it before anything else. ~32:00

claude --version says "command not found"?

The install finished but your shell can't find it yet — it needs to be added to your PATH. Flag it next time and we'll fix it in ten seconds; it's a one-liner. The version you should see is around 2.1.162. ~19:48

"Claude Code" vs. "Claude on the web" — which do I use?

Claude Code (the terminal one we used) works on the real files on your computer and can build whole apps. Claude on the web (claude.ai) runs in an isolated cloud box — great for one-off tasks like a quick script, but it can't build a full app on your machine. For this course: use Claude Code. ~40:00

Claude keeps stopping to ask permission → use Auto Mode

While building, Claude pauses on every file edit to ask "is this OK?" Press Shift+Tab to cycle modes. Auto Mode is the one to use ~99% of the time — before acting, Claude checks the action against a smaller safety model (Haiku) instead of stopping to ask you. Less babysitting, still safe. ~47:30

"Am I talking to Claude or to the terminal?"

Easy to confuse. If you see a folder name on the left of the line, you're in the plain terminal. After you run claude, you're talking to Claude Code. Type exit to drop back to the terminal.

New project = new folder

Keep each project in its own folder. To start a fresh one: cd .. goes up one level, then mkdir a new folder and cd in. Claude asks "do you trust this folder?" the first time it sees a new one — say yes.

Bonus tip: drive Claude from your phone

The /remote-control command lets you control a running session from your phone or the web app — handy for long builds. Catch: your computer has to stay on, unlocked, and plugged in. Optional, just a cool trick. ~43:00

The one idea to keep

The computer now understands what you mean

For fifty years you had to translate what you meant into rigid code, and the computer did exactly what you said — eggs-not-apples, or a $327M Mars orbiter lost to a units mismatch. AI flipped that: now the computer tries to understand what you mean. The cost of building has gone to roughly zero. The only question left is what you want to build.
