Week 2 · Background

What is Node.js?
And why do we need it?

Short version: Node.js lets you run JavaScript on your computer — not just inside a web browser. That's it. That's the whole thing.

JavaScript used to live in one place.

Before Node

JavaScript only ran inside web browsers. To do anything useful, you needed a webpage open. There was no way to run a .js file from your terminal.

After Node

Someone took the JavaScript engine out of Chrome and made it standalone. Now you can run a .js file the same way you'd run a Python script: node script.js.

Analogy: Node.js is to JavaScript what the Python interpreter is to Python — the program on your computer that knows how to execute the language.

OK, but why do we care?

Because the entire modern JavaScript toolchain runs on Node. Even if your app eventually runs in a browser, you need Node to build it, install its dependencies, and run a dev server.

  • npm (the package installer) comes with Node. npm install only works because Node is running it.
  • The dev server (the thing that gives you a live-reloading localhost:3000) is a Node program.
  • The Vercel CLI, the React build tools, TypeScript — all Node programs.
  • Even though your finished app runs in the user's browser, you ship it from your Node-powered workshop.

So in practice…

01

Install Node

One installer from nodejs.org. You now have node and npm on your machine.

02

Install project deps

npm install reads package.json and downloads everything the app needs.

03

Run / build

npm run dev starts the local server. npm run build produces the files Vercel will ship.

Bottom line: install it once, forget about it. It's the foundation everything else sits on.
