Setup · 2 of 4

Connect Claude to Supabase.

One command. From now on Claude can create tables, read rows, run queries for you — you stay in the chat.

~ — claude — 100×30
~/projects/deal-tracker $ claude mcp add supabase https://mcp.supabase.com/mcp
✓ Added MCP server: supabase
Type: http
URL: https://mcp.supabase.com/mcp
~/projects/deal-tracker $ claude
→ Authenticate supabase — opening browser…
Sign in and pick the organization you want Claude to access.

Setup · 3 of 4

Drop in your Supabase keys.

Open .env.local in your project. Paste two lines. Save. Don't commit it.
These are for the app itself at runtime — different from the MCP setup, which is for Claude.

.env.local — deal-tracker
# Drop your Supabase keys here, never in code.
# Vercel reads this when you deploy; Next.js exposes NEXT_PUBLIC_* to the browser.
NEXT_PUBLIC_SUPABASE_URL=https://mhyeepgaxaflatxwmksp.supabase.co
NEXT_PUBLIC_SUPABASE_ANON_KEY=sb_publishable_g4VsQH3NW5DvW5qyd-Ascw_nMmyz…
# That's it. Save the file. Don't commit it.

Spreadsheet vs database

Where the data lives matters.

Spreadsheet

One file
on your laptop.

  • ~1M rows — hard cap
  • Your copy
  • On your machine
Database

One shared copy
in the cloud.

  • No real limit
  • One shared copy
  • Many people at once
