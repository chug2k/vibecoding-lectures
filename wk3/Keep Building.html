Before we build · one concept

What that key is actually for

An API is just your code calling a service.

REQUEST → RESPONSE
Your code asks a service over the internet, and gets an answer back. Supabase was one already.
SAME SHAPE
Gemini · Claude · OpenAI — send text, get text. Mostly you just swap the address and the key.
WHY GEMINI
Free quota, no card. At Anduin we use LiteLLM — one key for all of them. Get one later.
Learn the shape once — it transfers to every model you'll ever use.07
